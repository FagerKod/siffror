Betalningsövning

Krav: Uppgiften ska fungera i komponenterna och ändrade värden ska stämma överens överallt.

Prova själv

Övning: Ingen betalning genomförs och inga uppgifter skickas.

Uppgifter för övningen

Ange ett positivt belopp med högst två decimaler, exempelvis 1 234,50. Högst 999 999 999,99 i denna övning. Mellanslag får gruppera tusental.

Betalning från Lönekonto: 1 234,50 kr

Gör så här: Byt konto, belopp och valuta. Läs sammanställningen och gå till knappen. Aktivera den för att få en övningsbekräftelse. Töm beloppet, prova 0 och ett felaktigt värde och aktivera knappen igen. Prova även 999 999 999,99.

Förväntat resultat: Sammanställning och knapptext visar det aktuella beloppet och valutan. Bekräftelsen innehåller rätt konto. Ett tomt fält visas som saknat belopp och blir inte noll. Ogiltigt format ger ett kopplat felmeddelande. Ingen gammal bekräftelse ligger kvar efter redigering.

HTML och implementation för betalningsövning
<label for="amount">Belopp</label>
<input id="amount" name="amount" type="text" inputmode="decimal">
<p>Betalning från Lönekonto: 1 234,50 kr</p>
<button type="submit">Betala 1 234,50 kr</button>
<p role="status"></p>

All uppdatering utgår från de aktuella fältvärdena. Fälttexten ändras inte under inmatning. Här används två decimaler enligt övningens formatregler. I React kan sammanställning och knapptext härledas från samma state. Statusregionen uppdateras vid bekräftelsen; hela formuläret är inte en live-region.

Komplett React-exempel för ändrade belopp

Konto, belopp och valuta ligger i state. Sammanställning och knapptext härleds från dessa värden vid varje rendering. Tomt är ett eget tillstånd. Fel visas vid försök att bekräfta och tidigare återkoppling rensas vid redigering.

Komplett komponent för ett befintligt React-projekt med stöd för JSX och Hooks. Spara som PaymentExample.jsx, importera komponenten och rendera <PaymentExample />. Sidans körbara övning ovan använder vanlig HTML och JavaScript; detta visar motsvarande mönster i React.

Övningen använder två decimaler för SEK och EUR och heltal av typen BigInt för hundradelar. Anpassa precision, beloppsgränser och validering till tjänstens regler. Detta är en gränssnittsövning utan betalningsanrop.

useId ger unika kopplingar mellan etiketter, hjälptexter och fält även om flera instanser visas. Statusregionen finns från början och uppdateras vid återkoppling. ARIA beskriver funktion, relationer och tillstånd, inte ett särskilt uttal av synliga tal.

Hämta PaymentExample.jsx

import { useEffect, useId, useRef, useState } from 'react';

function parseAmount(raw) {
  const text = raw.trim();
  if (!text) return { error: 'Ange ett belopp.', empty: true };
  if (!/^(?:\d+|\d{1,3}(?:[ \u00a0\u202f]\d{3})+)(?:[,.]\d{1,2})?$/.test(text)) {
    return { error: 'Ange ett positivt belopp med högst två decimaler och korrekt tusentalsgruppering.' };
  }
  const [whole, fraction = ''] = text.replace(/[ \u00a0\u202f]/g, '').split(/[,.]/);
  const cents = BigInt(whole) * 100n + BigInt(fraction.padEnd(2, '0'));
  if (cents === 0n) return { error: 'Beloppet måste vara större än noll.' };
  if (cents > 99999999999n) return { error: 'Ange högst 999 999 999,99.' };
  return { cents };
}

function formatAmount(cents, currency) {
  const whole = (cents / 100n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, ' ');
  const decimals = (cents % 100n).toString().padStart(2, '0');
  return `${whole},${decimals} ${currency === 'EUR' ? 'EUR' : 'kr'}`;
}

export default function PaymentExample() {
  const id = useId();
  const amountRef = useRef(null);
  const [account, setAccount] = useState('Lönekonto');
  const [amount, setAmount] = useState('1 234,50');
  const [currency, setCurrency] = useState('SEK');
  const [error, setError] = useState('');
  const [status, setStatus] = useState('');

  useEffect(() => {
    if (error) amountRef.current?.focus();
  }, [error]);

  // Härled presentationen från samma state, inte separata kopior i state.
  const result = parseAmount(amount);
  const formatted = result.error ? null : formatAmount(result.cents, currency);
  const summary = formatted
    ? `Betalning från ${account}: ${formatted}`
    : `Betalning från ${account}: ${result.empty ? 'Belopp saknas' : 'Beloppet behöver kontrolleras'} (${currency}).`;

  function clearFeedback() {
    setError('');
    setStatus('');
  }

  function submit(event) {
    event.preventDefault();
    if (result.error) {
      setError(result.error);
      setStatus('');
      return;
    }
    setError('');
    setStatus(`Övningen är klar. ${summary}. Ingen betalning har genomförts.`);
  }

  return (
    <section aria-labelledby={`${id}-title`}>
      <h2 id={`${id}-title`}>Betalningsövning</h2>
      <p>Ingen betalning genomförs. Inga uppgifter skickas eller sparas.</p>
      <form onSubmit={submit} noValidate>
        <label htmlFor={`${id}-account`}>Från konto</label>
        <select id={`${id}-account`} name="account" value={account}
          onChange={event => { setAccount(event.target.value); clearFeedback(); }}>
          <option value="Lönekonto">Lönekonto</option>
          <option value="Sparkonto">Sparkonto</option>
        </select>
        <label htmlFor={`${id}-amount`}>Belopp</label>
        <p id={`${id}-help`}>
          Ange ett positivt belopp med högst två decimaler, exempelvis 1 234,50.
          Högst 999 999 999,99. Mellanslag får gruppera tusental.
        </p>
        <input ref={amountRef} id={`${id}-amount`} name="amount"
          type="text" inputMode="decimal" value={amount}
          onChange={event => { setAmount(event.target.value); clearFeedback(); }}
          aria-describedby={`${id}-help ${id}-error`}
          aria-invalid={error ? true : undefined}
        />
        <p id={`${id}-error`}>{error}</p>
        <label htmlFor={`${id}-currency`}>Valuta</label>
        <select id={`${id}-currency`} name="currency" value={currency}
          onChange={event => { setCurrency(event.target.value); clearFeedback(); }}>
          <option value="SEK">SEK</option>
          <option value="EUR">EUR</option>
        </select>
        <p>{summary}</p>
        <button type="submit">
          {formatted ? `Betala ${formatted}` : 'Kontrollera betalningsuppgifterna'}
        </button>
      </form>
      <p role="status">{status}</p>
    </section>
  );
}
