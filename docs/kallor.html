Källor och vidare läsning

Kortguiden i Confluence är utgångspunkt för innehållet. Källorna nedan förklarar tekniken och skärmläsarnas kommandon. De garanterar inte ett visst svenskt uttal av ett exempel.

HTML och React

  • HTML Standard om inmatningsfält beskriver bland annat textfält och skillnaden mellan tal och sifferidentifierare.
  • React om input beskriver kontrollerade fält, value, onChange och markörproblem.
  • ARIA in HTML beskriver vilka element som kan ges tillgängliga namn.

Information och funktion

  • Information och relationer för samband mellan konto, rubrik, etikett och värde.
  • Användning av färg för information som inte får förmedlas enbart genom färg.
  • Etikett i namn för synlig text och kontrollens tillgängliga namn.
  • Statusmeddelanden för återkoppling utan fokusflytt.
  • Reflow för små vyer och förstoring.

  • VoiceOver-rotorn på iPhone.
